# 🧠 Excuse AI - Your Intelligent Escape Artist

Excuse AI is a premium, feature-rich Android application designed to generate clever, context-aware excuses for any situation. Whether you're late for work, skipping the gym, or need a witty social exit, Excuse AI has you covered with its unique "Tone Selection" engine.

## 🌟 Key Features

### 🎮 Tone-Based Logic
Unlike standard generators, Excuse AI allows you to choose the **Tone** of your delivery:
- **Professional**: Formal and serious (ideal for career/school).
- **Casual**: Friendly and relaxed (perfect for social circles).
- **Sarcastic**: Witty and playful (for those who love a bit of humor).

### 📂 Multi-Category Support
Extensive database covering:
- **Work** & **School**
- **Social Events**
- **Gym** (Workout skips)
- **Gaming** (Raid/Match commitments)
- **Late** (Tardiness specific)

### 💎 Premium Experience
- **Midnight Obsidian Theme**: Sleek, dark mode interface with glassmorphism effects.
- **Smart Animations**: Dynamic scale-and-fade transitions.
- **Instant Actions**: One-tap copy to clipboard and direct social sharing.
- **Offline Reliability**: Powered by a local SQLite engine—no internet or API keys required.

## 🛠️ Installation
The latest pre-built APK is ready for deployment:
- **Path**: `Excuse_AI_Advanced.apk`
- **Minimum SDK**: Android 24+

- **Language**: Kotlin
